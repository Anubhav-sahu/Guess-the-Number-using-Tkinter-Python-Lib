# Guess-the-Number-using-Tkinter-Python-Lib
A Numbers game where the computer selects a random number, and the player guesses it. The program provides hints ("too high" or "too low") after each guess until the player gets the correct answer.

How to Use:
Run the script.
A window will open with a text box for input and a button to submit guesses.
The program will give feedback ("Too Low" or "Too High") after each guess.
Once guessed correctly, the player can reset the game to start over.
